# Security policy

This is an independent community project and is not security-certified. Do not treat the examples as a complete production security design. Please do not report vulnerabilities in public issues. Contact the project owner privately through the contact method listed on the GitHub profile and include reproducible details, impact, and affected version. Avoid sending credentials or personal data. We will acknowledge reports and coordinate a fix and disclosure where possible.

Never commit secrets. Use IAM roles and narrowly scoped permissions. Review AWS charges, model access, guardrail policy, and data handling before sending real prompts to cloud services.
