# Bedrock Guardrails

`apply_guardrail(client, guardrail_id, version, text, source="INPUT")` sends `ApplyGuardrail` independently of a foundation model request. Use `source="INPUT"` for user text before model processing and `source="OUTPUT"` for generated text before returning it. Inspect `intervened`, `outputs`, `action_reason`, and `assessments`; never assume evaluation passed without checking the actual `action`. AWS failures are raised with a typed `BedrockRequestError` subclass and the original exception as the cause. Missing or unknown actions raise `ValueError`. Applications should fail closed and must not continue with unverified content when evaluation fails. Grant `bedrock:ApplyGuardrail` on the intended guardrail. Follow the [AWS independent ApplyGuardrail guide](https://docs.aws.amazon.com/bedrock/latest/userguide/guardrails-use-independent-api.html). Charges may apply.
